# DARK CRIMENET — user guide

Each page in the application also has a **How this page works** panel under its title, and the **?** button in the top bar opens a glossary. This file lists what every feature is for and where to read more.

| Page | What it is for | Who | More |
|---|---|---|---|
| Command Center | Summary of the selected case and where to start | all | – |
| Ingestion & Review | Read FIRs (English/Hindi/Hinglish), verify extracted facts | supervisor uploads; investigator verifies | [ingestion-and-translation](guide/ingestion-and-translation.md) |
| Cases & Notes | Case workbenches, tasks, notes | all (write for supervisors) | – |
| Persons of Interest | Ranked leads with evidence; confirm or dismiss | analysts | [suspects](guide/suspects.md) |
| Knowledge Graph | How people, phones, vehicles and accounts connect | all | [timeline-map-graph](guide/timeline-map-graph.md) |
| Network AI | Suggested missing links, explanations, key connectors | analysts | – |
| Timeline & Map | When and where things happened; works offline | analysts | [timeline-map-graph](guide/timeline-map-graph.md) |
| Social Media Intelligence | Import lawfully obtained posts; risk-language flags, coordinated accounts, links to the case | all read; supervisors import | [social-media-intelligence](guide/social-media-intelligence.md) |
| Surveillance Reports | Authorised operations, tamper-evident field log, PDF/Word/HTML/JSON reports | all read; supervisors write | [surveillance-reports](guide/surveillance-reports.md) |
| AI Copilot | Ask questions; answers cite sources | analysts | – |
| Signals & Evidence | Alerts, cross-FIR links, hashed evidence vault | all | – |
| Data Integrity | Signed hash-chained ledger; one-click integrity check; offline verifier | supervisor, admin, auditor | [data-integrity](guide/data-integrity.md) |
| Approvals & Deadlines | Maker-checker approvals, deadlines, watchlists | all | – |
| Oversight | Management dashboard, legal packs, backups | supervisor, admin, auditor | – |
| Reports & Audit | Case reports; tamper-evident audit log | report / audit | – |
| Access Requests | Supervisor then administrator approval of new users | supervisor, admin | [access-and-roles](guide/access-and-roles.md) |
| Admin Portal | Users, roles, two-step sign-in policy, case access, demo data | admin | [roles](roles.md) |

Two-step sign-in (authenticator app) is described in [two-step-sign-in](guide/two-step-sign-in.md). Every page has a **back** button in the top bar (also Alt + ←). Uploading a FIR with no case selected opens a pop-up to create the case first.

Removed in v5.1: Pattern Lab, Cyber Forensics, cross-case hits, the what-if sandbox and the Gaps tab. Removed earlier because they did not help police work enough: the freeform Link Canvas, the insider-risk tool, the case-intelligence and model-quality modules.
