# Synthetic FIR OCR Validation Pack

This folder contains 20 synthetic, authorized-only FIR-like scan images generated for local OCR and FIR field extraction demonstrations. They contain no real personal or investigative data.

Suggested demo:
1. Start the application.
2. Create/select an investigation case.
3. Open Ingestion & NLP.
4. Upload several `ocr_fir_samples/*.jpg` files together.
5. Review OCR confidence, extracted FIR fields, translation and human verification.
6. After verification, inspect the same case in Knowledge Graph, Analytics, Timeline + Map, Signals + Evidence, AI Copilot and Reports + Audit.

These images are deliberately synthetic and should never be described as real police evidence.
